## About me

복잡한 아이디어를 직관적인 제품으로 바꾸는 프론트엔드 개발자입니다.
AI를 활용한 제품, 실시간 협업 경험, 그리고 손에 잡히는 인터랙션을 만드는 데 관심이 많습니다.

- 🧩 사용자 흐름부터 데이터 구조까지 함께 고민합니다.
- ⚡ 빠르게 만들고, 실제 사용 경험을 보며 다듬습니다.
- 🌱 웹을 중심으로 모바일과 컴퓨터 비전까지 영역을 넓히고 있습니다.
